# CHRISTINA Agent Kernel

Host-owned execution and orchestration kernel for **CHRISTINA** — Composable Harness Reactive Intelligent Systems Tool Integration Neural Agents.

The package provides:

- Durable sessions, runs, events, approvals, memory, skills, and checkpoints
- Cross-platform CLI and OpenClaude runtime adapters
- Host-owned policy, budgets, hooks, structured output, and tool boundaries
- Six-specialist routing and dependency-aware parallel execution
- Conflict-aware synthesis and confidence scoring

See `../../docs/CHRISTINA_ORCHESTRATOR_0.6.md` for the orchestration contract.

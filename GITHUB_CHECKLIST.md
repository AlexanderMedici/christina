# GitHub Publication Checklist

- [ ] Replace every `YOUR_GITHUB_USERNAME` placeholder.
- [ ] Review `LICENSE.md`, `NOTICE`, and `THIRD-PARTY-NOTICES.md`.
- [ ] Run `bun install`.
- [ ] Run lint, typecheck, and tests.
- [ ] Test a local model provider.
- [ ] Test private-library authorization with sample public-domain material.
- [ ] Enable Issues, Discussions, private vulnerability reporting, and branch protection.
- [ ] Configure Actions variables for the repository owner and name.
- [ ] Confirm no `.env`, private index, transcript, credential, or signing file is staged.
- [ ] Push `main`.
- [ ] Tag `v0.8.0` only after CI passes.

# Windows bootstrap installer

The bootstrap installer embeds the complete repository and installs it under `%LOCALAPPDATA%\Programs\CHRISTINA`.

`CHRISTINA.exe` launches `Launch-CHRISTINA.ps1`, which installs missing prerequisites and workspace dependencies on first use, then opens the Electron desktop application.

This alpha bootstrap path is separate from the packaged Electron/NSIS production installer generated by `.github/workflows/windows-installer.yml`.
